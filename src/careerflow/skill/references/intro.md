# 自我介绍与 HTML 演示

根据岗位、已有档案与目标时长取舍内容。时长未说明且上下文无提示时用约 1 分钟起草并说明假设；用户指定时长就按指定时长。保留一个定位和最有说服力的一到两段经历，不把简历全文搬到幻灯片。

讲稿把“我能解决什么问题”讲清楚，结果只用已记录的证据。规划与动机来自用户意向，不编造对企业的热爱或长期承诺。项目中的个人职责与团队成果分开。

产出可直接讲的稿件、分页要点和时间分配。字数只能作为初估，实际是否超时由朗读计时确定；没做朗读就写“时长待实测”。需要 3/5 分钟版时增加证据深度，不靠增加形容词延长。

可执行 `render intro --output <新文件.html>` 生成档案事实的 HTML 草稿，再依据讲稿修改。演示使用本地 CSS/JS，不依赖 CDN；转义姓名、项目文本等数据。至少检查下一页/上一页、方向键、首尾边界、小屏可读性与打印。没有浏览器能力时说明未做交互验收。

验收：每页只有一个中心；稿件和页面事实一致；页面显示正常但未经朗读时，不把计时写成通过。
