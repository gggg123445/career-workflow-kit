# 岗位研究

先读城市、方向、毕业时间等硬约束和已有经历。已有目标 JD 时围绕该岗位研究；尚无目标时先给小批可比较的岗位，不强制凑满数量或覆盖不相关行业。

招聘批次、截止时间、资格、办公地和职位是否仍开放，以企业招聘页或正式公告核验，记录链接、公告日期与核验日期。公开讨论只能作为有限参考，不把传闻当成组织事实。无检索能力时对用户提供的岗位做离线比较，标明未核验开放状态。

逐岗位说明：硬约束是否满足、经历中的匹配证据、实际差距、截止时间、准备成本、下一步动作。冲刺/主力/备选只是准备分配，不是录取概率。薪资不公开就留空，不用无依据区间补齐。

只有用户采纳的目标才建投递记录；`add` 是记账，不是提交申请。

```text
python scripts/careerflow.py --workspace <目录> add --company <公司> --position <岗位> --city <城市>
```

交付岗位比较清单及来源。检查排除项是否被尊重、JD 对应的是不是当前招聘批次、每条推荐能否解释为什么适合，以及哪些资格仍需用户确认。
