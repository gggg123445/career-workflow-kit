# 面试复盘

从转写或用户回忆还原 Q/A，保留原句与材料局限。说话人不清楚时标注不确定，不补写缺失回答。先确定输入是录音、有时间戳转写、普通转写还是回忆，能评价的维度随证据变化。

内容上检查是否切题、关键知识是否正确、案例是否支撑结论、是否解释了验证与取舍。表达上只评价能观察到的结构、冗余与措辞；没有音频或可信时间信息时不估语速、停顿或情绪。面试官意图只能作为推断，不能当作事实。

挑影响最大的两到三个问题，逐项给出“原句 → 为什么影响回答 → 保持事实的改写 → 下一次练习”。涉及个人经历的改写仍以档案为依据，不替用户发明新成果。不要把诚实承认知识边界当作一律应该隐藏的弱点。

工作强度、团队协作等反问可以合理提出，帮助用户判断双向匹配，不把合理的工作条件诉求称为禁忌。

交付 Q/A 摘要、证据化诊断、改写与少量可执行练习，关联到这次投递记录。练习可以直接引用已有备考条目；没有既有资源时给自足的练法，不生成无效链接。验收时说明哪些结论是观测、哪些是推断、哪些维度未评估。
